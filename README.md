# 🛍️ RedStore E-Commerce Frontend Website

This project is a responsive e-commerce frontend inspired by **RedStore**. It showcases product listings, a promotional offer section, testimonials, brand logos, and a basic login interface. Built using **HTML**, **CSS**, **Bootstrap**, and **Font Awesome**.

## 📁 File Structure

├── index.html # Main homepage with products and offers
├── Login.html # Login page with basic form
├── style.css # Main stylesheet with responsiveness and design
├── Img/ # Folder for product, brand, and logo images


---

## ✨ Features

- 🏠 Homepage with:
  - Header, Hero Banner
  - Featured and Latest Products
  - Product Ratings using Font Awesome
  - Promotional Offer Section
  - Customer Testimonials
  - Brand Logos
- 🔐 Login Page with styled input fields
- 📱 Fully responsive layout with media queries
- 💡 Toggle menu for smaller devices
- 🎨 Modern UI design with custom CSS & Bootstrap
